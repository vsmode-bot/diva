1. Як правильно доглядати за сатиновим комплектом із мереживом?
Рекомендується ручне прання в прохолодній воді (до 30°C) або делікатний режим у пральній машині з використанням мішечка для прання білизни. Використовуйте м'які мийні засоби, без відбілювачів. Не викручуйте сильно. Сушити краще в розправленому вигляді, уникаючи прямих сонячних променів.

2. Чи підходить цей комплект для чутливої шкіри?

4. Як точно визначити свій розмір?
Для визначення розміру бюстгальтера виміряйте обхват під грудьми та обхват грудей по найвищих точках. Для трусиків – обхват стегон по найширшій частині. Порівняйте свої виміри з нашою таблицею розмірів, представленою в розділі "Таблиця Розмірів та Вибір Вашого Ідеалу".
